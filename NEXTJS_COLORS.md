# Next.js Color Palette Reference

Based on Next.js official website and documentation design system.

## Light Mode Colors

### Background Colors
- **Primary Background**: `#ffffff` (pure white)
- **Secondary Background**: `#fafafa` (neutral-50)
- **Card Background**: `#ffffff` with subtle shadow
- **Code Background**: `#f6f8fa` (light gray)
- **Border**: `#e1e4e8` (light gray border)

### Text Colors
- **Primary Text**: `#24292e` (dark gray, almost black)
- **Secondary Text**: `#586069` (medium gray)
- **Muted Text**: `#6a737d` (lighter gray)
- **Link Text**: `#0070f3` (Next.js blue)
- **Code Text**: `#24292e` (same as primary)

## Dark Mode Colors

### Background Colors
- **Primary Background**: `#000000` (pure black)
- **Secondary Background**: `#111111` (very dark gray)
- **Card Background**: `#111111` (very dark gray)
- **Code Background**: `#161b22` (dark gray)
- **Border**: `#30363d` (dark gray border)

### Text Colors
- **Primary Text**: `#f0f6fc` (almost white)
- **Secondary Text**: `#8b949e` (medium gray)
- **Muted Text**: `#6e7681` (darker gray)
- **Link Text**: `#58a6ff` (light blue)
- **Code Text**: `#f0f6fc` (almost white)

## Semantic Colors

### Success
- Light: `#28a745`
- Dark: `#3fb950`

### Warning
- Light: `#ffc107`
- Dark: `#d29922`

### Error
- Light: `#dc3545`
- Dark: `#f85149`

### Info
- Light: `#0070f3` (Next.js blue)
- Dark: `#58a6ff`

## Usage Notes

- Next.js uses a very high contrast design in dark mode (pure black background)
- Light mode uses subtle grays with pure white background
- The signature Next.js blue (`#0070f3`) is used consistently for links and accents
- Dark mode borders are more subtle than light mode
- Code blocks have slightly different backgrounds than the main content area
