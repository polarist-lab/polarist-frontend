# Combining Characters into Syllables

## Introduction

Now that you understand vowels and consonants, it's time to combine them! Korean syllables follow specific patterns that make reading predictable and logical. Unlike linear alphabets, Korean arranges letters into **syllable blocks** - square units that contain all the sounds for one syllable.

---

## Understanding Syllable Blocks

### What is a Syllable Block?

Korean text isn't written in a line like English. Instead, letters are arranged in **blocks** that represent complete syllables:

- **English**: C-A-T (linear)
- **Korean**: 갈 (block containing ㄱ + ㅏ + ㄹ)

Each block is roughly the same size, creating uniform, beautiful text that's easy to read.

---

## Basic Syllable Patterns

### Pattern 1: CV (Consonant + Vowel)
The simplest Korean syllable structure.

#### Vertical Vowels (ㅏ, ㅓ, ㅣ)
Letters arrange **left-to-right**:

- **가** = ㄱ + ㅏ (ga - "go")
- **너** = ㄴ + ㅓ (neo - "you")  
- **미** = ㅁ + ㅣ (mi - "beauty")

#### Horizontal Vowels (ㅗ, ㅜ, ㅡ)
Letters arrange **top-to-bottom**:

- **고** = ㄱ + ㅗ (go - "high")
- **누** = ㄴ + ㅜ (nu - "who")
- **으** = ㅇ + ㅡ (eu - sound of strain)

### Pattern 2: CVC (Consonant + Vowel + Consonant)
Adding a final consonant to the syllable.

#### With Vertical Vowels
- **간** = ㄱ + ㅏ + ㄴ (gan - "liver")
- **넘** = ㄴ + ㅓ + ㅁ (neom - "over")
- **밑** = ㅁ + ㅣ + ㅅ (mit - "bottom")

#### With Horizontal Vowels  
- **곰** = ㄱ + ㅗ + ㅁ (gom - "bear")
- **눈** = ㄴ + ㅜ + ㄴ (nun - "eye/snow")
- **음** = ㅇ + ㅡ + ㅁ (eum - "sound")

### Pattern 3: Complex Syllables
Korean can handle more complex structures too.

#### CVCC (Consonant + Vowel + Consonant + Consonant)
- **닭** = ㄷ + ㅏ + ㄹ + ㄱ (dak - "chicken")
- **넋** = ㄴ + ㅓ + ㄱ + ㅅ (neok - "soul")

#### CCV (Consonant + Consonant + Vowel)  
Using consonant clusters:
- **크** = ㅋ + ㅡ (keu - "big")
- **트** = ㅌ + ㅡ (teu - part of "truck")

## Syllable Block Positions

### Understanding the Grid

Every Korean syllable follows a predictable grid:

```
┌─────┬─────┐
│  1  │  2  │  Initial Consonant (1)
├─────┼─────┤  Vowel (2 or 3)  
│  3  │  4  │  Final Consonant (4)
└─────┴─────┘
```

### Position Rules

#### Position 1: Initial Consonant (초성)
- **Always present** - every syllable starts with a consonant
- **Silent ㅇ**: When syllable starts with vowel sound, use ㅇ placeholder
- **Examples**: ㄱ in 가, ㅇ in 아

#### Position 2/3: Vowel (중성)
- **Vertical vowels** (ㅏ, ㅓ, ㅣ) use position 2
- **Horizontal vowels** (ㅗ, ㅜ, ㅡ) use position 3  
- **Complex vowels** may use both positions

#### Position 4: Final Consonant (종성)
- **Optional** - not every syllable has a final consonant
- **Bottom of the block** when present
- **Examples**: ㄴ in 간, ㅁ in 곰

## Visual Assembly Practice

### Step-by-Step Construction

#### Building 감 (gam - "emotion")
1. **Start with grid**: ㅁ in position 1
2. **Add vowel**: ㅏ in position 2 → 마  
3. **Add final**: ㅁ in position 4 → 감

#### Building 공 (gong - "ball")
1. **Start with grid**: ㄱ in position 1
2. **Add vowel**: ㅗ in position 3 → 고
3. **Add final**: ㅇ in position 4 → 공

### Size Adjustment Rules

Korean letters automatically **resize** to fit the block:

- **Two elements** (CV): Both get more space
- **Three elements** (CVC): All compress to fit
- **Four elements** (CVCC): Maximum compression

#### Examples:
- **가** vs **간** vs **갑**: Notice how ㄱ and ㅏ get smaller as more elements are added

## Reading Direction and Flow

### Block-by-Block Reading

Korean text flows in **syllable blocks**:

```
안녕하세요
(An-nyeong-ha-se-yo)
"Hello"

안 | 녕 | 하 | 세 | 요
5 separate syllable blocks
```

### Within Each Block

Read elements in **construction order**:
1. **Initial consonant** (top-left)
2. **Vowel** (right or bottom)  
3. **Final consonant** (bottom)

#### Example: 한글 (Hangul)
- **한**: ㅎ → ㅏ → ㄴ = han
- **글**: ㄱ → ㅡ → ㄹ = geul

## Common Syllable Patterns in Korean

### High-Frequency Patterns

#### Simple CV Syllables
- **가** (ga) - "go"
- **나** (na) - "I"
- **다** (da) - "all"  
- **마** (ma) - "horse"
- **바** (ba) - "sea"
- **사** (sa) - "four"

#### Common CVC Syllables
- **한** (han) - "one" or "Korea"
- **말** (mal) - "word/horse"
- **집** (jip) - "house"
- **물** (mul) - "water"
- **밥** (bap) - "rice/meal"

### Syllable Families

Notice how changing one element creates word families:

#### ㅏ Family
- **가** (ga), **나** (na), **다** (da), **라** (ra), **마** (ma)

#### -ㄴ Ending Family  
- **간** (gan), **난** (nan), **단** (dan), **란** (ran), **만** (man)

## Special Cases and Notes

### Silent ㅇ (이응)

When a syllable starts with a vowel sound, use **ㅇ** as a placeholder:

- **아** = ㅇ + ㅏ (a - "oh!")
- **이** = ㅇ + ㅣ (i - "this")
- **을** = ㅇ + ㅡ + ㄹ (eul - object marker)

### Double Final Consonants

Some syllables can have two final consonants:

- **닭** = ㄷ + ㅏ + ㄹ + ㄱ (dak - "chicken")
- **삶** = ㅅ + ㅏ + ㄹ + ㅁ (sam - "life")

### Pronunciation vs. Spelling

Some syllables change pronunciation based on what follows:

- **한국** (han-guk): ㄴ + ㄱ → "hang-guk" sound
- **물가** (mul-ga): ㄹ + ㄱ → "mur-ga" sound
